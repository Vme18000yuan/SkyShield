# 根域名资产归集

「资产 → 根域名」会显示由域名目标、子域名、网站服务和接口域名归集出的根域名。例如，`z.skyshield.example` 会归集到 `skyshield.example`。归集使用公共后缀规则，`api.example.co.uk` 会归集到 `example.co.uk`，`api.tenant.github.io` 会归集到 `tenant.github.io`。IP 地址、单标签主机名和公共后缀本身不会被当作根域名。

根域名与手动登记的相同根域名共用同一资产身份；多个目标或子域名不会创建重复条目。没有直接登记记录的根域名在资产列表标记为「推导」。此标记说明其来自已有目标或资产，不会自动新增扫描目标，也不会扩大现有目标的扫描范围。对于仅授权 `team.skyshield.example` 的目标，系统不会把推导出的 `skyshield.example` 作为该子域名目标范围内的 AI 任务资产。

服务启动后，后台任务分批补齐已有数据，并持续处理新增和更新。资产列表的根域名页会自动刷新。已有资产量较大时，首次补齐会逐步完成。根域名的首次和最近发现时间会参考其仍可见的来源资产；目标被删除后，仅由该目标产生且没有其他可见来源的推导根域名不会继续显示。手动独立登记的根域名保留原有可见性。

资产监控大屏会把根域名归入原来源所属的组织，并可使用来源资产的 IP 或已记录国家信息展示地域。该关联仅用于资产归集和展示。

本次升级使用数据库迁移 `000028_root_domain_projection`。本地模式在扫描结束后执行 `./local.sh start` 即可构建、迁移并自动启动后台归集，无需手动添加 `skyshield.example`。现有扫描任务运行时不要强制重启 Agent。
