# ARTEX AI 能力迁移对照

基准为同级目录 `ARTEX` 的源码，目标为当前 SkyShield。此表记录功能和实际运行链路，不能仅凭页面、数据表或依赖库存在判定为完成。

| 范围 | ARTEX 基准 | 当前差距与迁移要求 |
| --- | --- | --- |
| AI 对话 | Agent/会话模型选择、会话管理与消息历史、附件、停止、侧问、审批、工具及 Skill/MCP 运行 | 原版页面、会话操作、附件、侧问、@ 引用、工具审批与模型兜底审查已接入；任务审批定位工具调用及其前后上下文已接入并部署至本机；完整内置工具链仍待迁移。 |
| AI 任务 | 目标拆解、Planner/Worker/MainAgent、任务队列与并发、意图控制、覆盖、范围/约束、关联任务和资产、模型链与恢复 | 核心编排、种子意图、直接来源任务只读继承、模型链、目标和约束维护、意图重跑、暂停恢复、人工消息、两种意图删除、分类和模板已接入；MainAgent 支持独立后台对话、分段、停止、附件、执行轨迹和分段旁路提问；任务范围、资产归集、粗略覆盖度、覆盖图和 DSL 查询已接入，覆盖图已补充按父节点及类型折叠、分批展开和详情抽屉并部署至本机；图布局及原版任务页面、归档恢复仍需完整对齐。 |
| AI 计划任务 | 多种时间窗口、任务绑定、立即运行、暂停恢复、计划历史及任务状态协调 | 已迁移原版页面、时间窗口、任务绑定、启停和历史，需与整体任务流程一起继续验收。 |
| Agent 设置 | 内置与自定义 Agent；提示词编辑/版本/变量/预览；运行预算、模型绑定、收尾、工具/Skill/MCP 可见性及自定义 Agent 触发器 | 默认 Agent 与配置、触发器调度已接线；报告 Agent 的证据读取、自动触发和报告回写已接入；复测已接入 AI 发现的详情和任务图。Auto 已在源码中接入创建和修改 Skill 文件、自定义工具与 MCP，并可查询模型配置、向任务添加战略提示；这些能力已部署至本机，其他默认工作流仍需实现。 |
| 模型和工具 | Agent 绑定优先于任务/会话选择，再回退全局；任务链支持额度耗尽切换；内置和自定义工具可按 Agent 配置 | 模型设置、任务链、受控宿主执行、搜索、Skill/MCP、工具审批、资产登记和意图派发的资产规则及现有扫描黑名单已接入；任务及对话隔离录制、任务流量查看、漏洞手动/自动证据绑定与凭据流量匹配已接入，本地浏览器 MCP 已通过真实 HTTPS、代理及录制联调。全局流量列表已部署至本机；全局流量删除、远程浏览器流量及其他内置工具仍待完成，SSE 与至少 5 MiB 的流式流量沿用原版录制限制。 |
| 模型用量与录制 | 按调用记录模型、任务、Agent、Token、状态并按模型/日期汇总；可选录制和查看模型请求与响应 | 新版账本已记录新调用，按账号隔离，LLM 设置页、任务页及总览可查看；总览支持配置筛选、累计输入与输出、缓存读取和 UTC 日期趋势，旧调用不自动补录。模型原始请求/响应已支持按账号加密录制、筛选和按任务删除，单侧 8 MiB 上限；原版仪表盘和独立录制页面布局仍有差异。 |
| 资产情报 | 按显式关联资产查看任务情报及凭据流量 | 资产列表已接入只读情报视图、来源任务和关联流量，复用统一资产库并检查账号和目标权限。 |
| 漏洞发现 | 任务发现列表、证据与报告、状态处理、来源继承、发现归并和通知 | 发现列表、人工归并与拆分、相似检索、统一报告和操作记录已实现；Reporter 可在来源任务内检索、直接归并、回写报告并提出待人工确认的建议，跨任务历史审查具备原子排队、所选范围、结论验收及停止控制。发现创建与状态变更已接入账号隔离的站内通知，以及原版六类外部渠道、实时/汇总、过滤、限流、重试与投递记录；外部渠道凭据加密并使用系统 HTTP 代理。隔离数据库、真实 Agent 和浏览器夹具覆盖权限及主要交互；这些功能已部署至本机。AI 发现状态与平台风险审核独立。 |
| 数据与权限 | ARTEX 自有任务图、会话、配置和资产存储 | 迁移时必须保留 SkyShield 现有会话/任务/模型配置和统一资产库，并继续通过当前登录与租户权限边界访问。 |

主要源码：ARTEX 的 `server/engine.go`、`server/task_llm.go`、`server/conversations.go`、`server/scheduler.go`、`server/server_mgmt.go`、`web/src/components/agent-editor.tsx`；SkyShield 的 `server/internal/airuntime`、`server/internal/modules/aiworkbench`、`server/internal/modules/aisettings` 和 `frontend/components/ai`。
