# 应用识别与归集

系统从已有 Web 站点的有效标题或明确产品指纹识别应用候选。HTTP 错误响应、拒绝访问、重定向说明、通用登录页，以及仅有 Nginx、Vue 等框架信息的站点不会单独生成应用。同一可注册根域名下名称相同的站点归集为一个候选；不同根域名默认分开，避免仅凭名称混淆不同业务。标题和指纹只是线索，不证明应用归属或产品身份。

在「资产 → 应用」点击应用，可查看归集的站点和每条识别依据。组织筛选和根域名概览沿用原站点的组织、目标关系。手动添加应用时可填写绑定域名；名称、根域名及组织或目标均匹配时，系统会将相同候选与手动应用合并。存在多个可能的手动匹配时不会自动选择。

历史站点通过可恢复的后台任务分批处理；新站点及标题、状态、指纹变化通过持久队列增量更新。组织与目标解除关联时，原有的手动应用匹配立即失效，后台分批重新归集受影响的站点。站点失效、删除或不再满足识别条件时移除对应关联，原始站点和应用标识不会被批量删除。整个过程不发起新的目标网络请求，也不扩大扫描范围。

该功能基于现有 Web 证据，不会自动发现移动应用商店中的客户端，也不保证识别所有业务应用。缺少有效标题或产品指纹的应用可手动登记并绑定域名。
