# ARTEX AI 完整迁移验收

基准：同级目录 `ARTEX`，以源码实际行为为准。当前迁移尚未完成；只有同时完成页面、API、持久化、运行时接线及回归验证的条目才可标记完成。原有登录、租户/用户权限、统一资产、HTTP 代理与已有 AI 数据需要保留。

## 范围

- [ ] LLM：原版卡片与抽屉、三种协议、模型列表、未保存配置测试、Key 提示、代理、RPS/RPM、上下文窗口、思考开关/强度、流式开关、输出上限/字段、自定义会话头、优先级/排除轮询、五层重试、共享限流、故障转移与熔断恢复、任务模型链。
- [ ] Agent：六个固定 Agent 原始提示词、reporter/retester 默认自定义 Agent、完整预算/模型/交互终端/搜索配置、提示词版本/变量/预览/恢复、收尾与任务超时收尾、工具/Skill/MCP 可见性、触发器与串行/并行/合并策略。
- [ ] 对话：原版左右布局与空白草稿、Agent/模型选择、流式活动与 Markdown、会话筛选/重命名/置顶/删除/批量删除、停止、附件、@ 引用、侧问、审批和工具执行详情。
- [ ] 任务与默认流程：Goals → 事件驱动 Planner → Worker 池 → MainAgent；目标/约束/范围、意图控制/消息/重跑、队列/优先级/分类/备注、模板、继承/关联资产、覆盖图、发现与执行视图、任务模型链、恢复与收尾。
- [ ] 计划任务：原版日历/时间窗口/任务关联、暂停恢复、立即运行、运行历史、任务状态协调。
- [ ] 工具与运行能力：原版内置及自定义工具、受控本地执行、文件/终端/网络访问、Skill/MCP 装配、人在环路审批、完整调用轨迹。

## 验收方式

使用本地 HTTP 模型夹具验证配置确实进入真实请求、模型切换和重试行为；数据库集成覆盖持久化与权限；浏览器验证对应 ARTEX 页面交互。不得仅凭依赖库、表结构、菜单或 DTO 存在判定完成，也不得用固定成功响应替代功能。

## 当前进度

- LLM 设置原版界面、模型协议与连接测试、限流/重试/故障转移和任务模型链已接线；数据库与真实 HTTP 模型夹具覆盖请求参数、额度耗尽切换、并发切换和配置变更，浏览器覆盖主要设置交互。
- 逐次模型调用用量总账已接入具体模型提供方，记录账号、模型配置、任务或会话、Agent、耗时、Token 和成功/失败/中断状态，不保存提示词或模型回复。模型池切换和安全窗口重试会分别计量；任务 MainAgent/Worker、对话、报告 Agent、旁路提问、审批审查及凭据整理使用相同账本。LLM 设置页提供按配置和日期统计，任务页提供按模型统计；数据按账号隔离，迁移前的历史调用不自动补录。隔离数据库、真实 HTTP 模型夹具、并发和浏览器测试覆盖模型切换、失败、账号和任务限制。原版仪表盘布局仍未完全对齐。
- LLM 设置页已接入可选请求/响应录制：记录真实 HTTP 请求体、响应及解析结果，内容按账号使用 AI 密钥加密；可按任务名称、模型和会话筛选、查看及删除所选任务的录制，用量总账不随录制删除。开关作用于之后开始的调用，单侧内容超过 8 MiB 会截断并在页面提示；删除任务录制会阻止删除前已开始的调用重新写入。隔离数据库、真实流式 HTTP 模型夹具、并发和浏览器测试覆盖开关、密钥、加密、访问隔离和删除。页面位置及布局与 ARTEX 独立录制页仍有差异。
- 六个内置 Agent、可编辑的 reporter/retester 预设、提示词版本和预览、收尾、可见性及触发器调度已接线。报告 Agent 已能由成功的漏洞登记自动触发，读取所属漏洞的证据版本并保存报告，漏洞详情可查看 Markdown；数据库测试覆盖触发到回写的真实 Agent 工具链、失败登记跳过、重复调用、版本冲突、用户隔离和运行租约。复测 Agent 已接入 AI 发现对应的漏洞详情和任务图，覆盖并发去重、独立会话、证据快照、停止与完成后状态更新；尚未关联 AI 发现的扫描器漏洞还不能从该入口复测，完整内置工具仍未完成。
- Auto Agent 的 `create_skill`、`update_skill_file`、`create_custom_tool`、`update_custom_tool`、`create_mcp`、`update_mcp` 已在源码中接入现有 Skill 包、工具目录和 MCP 存储。写入要求当前账号具有管理员权限、会话运行租约有效且工具仍授权给该 Agent；写入和工具调用回执在同一事务中提交，重复调用不会重复创建，已停止运行不能继续写入。修改 MCP 连接目标时必须重新提供或明确清空已有环境变量/请求头凭据，避免把原凭据带到新目标。现有用户自定义工具若与新内置工具同名，优先保留用户原工具。隔离数据库和真实 Auto 对话夹具覆盖六个工具、事务回滚、并发去重、权限、停止及 MCP 凭据；这些工具已部署至本机；写工具要求独立对话运行租约，尚不支持从任务内 Planner/Worker 调用。工具输入仍可能保存在 Agent 的对话执行轨迹中，自定义工具执行规格也沿用现有工具目录的明文存储。原版按主机跨任务硬删除资产的工具尚未迁移。
- Auto 的 `list_llm_profiles` 与 `add_task_hint` 已在源码中接入：前者只返回模型配置的 ID、名称、模型、协议和默认状态；后者可向本账号的任务单条或批量提交战略提示，按条返回编号及错误，保存目标范围内的资产关联与允许的流量引用，并通过持久事件交给 Planner。提示不会自动恢复已暂停或未排队的任务；流量引用受 Agent 自动绑定开关限制。隔离数据库、真实 Auto 对话及 Planner 夹具覆盖模型配置脱敏、部分成功、越权资产、并发重放、停用与停止、任务归档和实际消费。此项及迁移 73 已部署至本机。
- 独立对话中绑定原版 `report_finding` 或 `list_findings` 时，已接入 ARTEX 原始的无任务上下文提示，引导 Agent 使用跨任务提示或查询工具；任务内仍使用实际任务图实现。工具默认绑定保持原版，`list_findings` 不会自动绑定给 Auto。隔离的真实 Auto 对话已验证两种提示；此项已部署至本机。
- 原版 `list_companies` 已在源码中对接现有组织、目标和统一资产库，返回组织名称、目标范围及资产数量；绑定目标的任务只返回该目标所属组织及该目标内资产。最多返回 200 个组织和每个组织 100 条目标，超出时返回相应截断标记。隔离数据库、真实 Auto 与 Planner 夹具覆盖名称搜索、数量、任务范围、账号和租约；此项已部署至本机。原版修改公司资产范围的 `add_company_scope` 仍未迁移。
- 对话已迁移原版界面、会话操作、附件、侧问和 @ 引用；引用会读取服务端可见记录并保留原始会话文本；“漏洞”使用 AI 发现编号，“风险”使用平台风险编号，数据库与浏览器测试已覆盖。Skill 包管理、本地运行和 HTTP/SSE/stdio MCP 已接线，Python 虚拟环境按单次脚本执行隔离；stdio MCP 可运行明确配置的外部解释器和文件，凭据通过一次性管道传递。默认浏览器 MCP 已用实际 Playwright MCP 和本机 Chromium 测试 HTTPS 访问、系统代理、流量录制、关闭录制和失效租约；测试包预先安装在隔离目录。为兼容 Linux 本地文件隔离，Chromium 使用单进程模式；带录制功能启动的浏览器会在该次运行中忽略 HTTPS 证书错误，包括运行中关闭录制后。
- 工具审批已接入原版规则、人工允许/拒绝/超时、模型兜底审查、规则设置和审批记录页面；真实 Agent 工具调用、运行租约、用户隔离、取消和模型审查使用隔离数据库与本地 HTTP 模型夹具验证。任务审批已在源码中支持定位原始工具调用及同一 Planner、意图或 MainAgent 会话的前后上下文，并可逐页加载；目标失效或任务归档后不再返回该定位和任务活动详情。隔离数据库、组件及 Chromium 夹具覆盖三类会话、分页、用户隔离和失效边界；此项已部署至本机，任务执行页整体布局仍与 ARTEX 不同。
- 全局资产拦截和任务级拦截/允许规则已迁移原版默认规则、设置页和任务内编辑；创建任务时可一并保存规则，再将任务放入运行队列。规则按“全局及任务拦截优先，再检查任务允许范围”作用于 AI 资产登记和关联意图派发；同时复用产品的全局扫描黑名单，关联目标时还复用目标黑名单。数据库、真实 Agent 流程和浏览器已覆盖；这些规则不等同于对任意终端命令建立了网络出口防火墙。
- Goals → Planner → Worker → MainAgent 的核心运行链、模型链、Worker 池、并发和不限时预算已接线；目标拆解已接入统一工具、Skill、MCP 装配，并验证了自定义 HTTP 工具调用；目标与操作约束支持人工增删改，目标变更持久化唤醒规划者，约束按设置注入 Planner/Worker；`goal_met` 保持原版默认不绑定，手动绑定 Planner 后可实际调用。单条失败意图及批量阻塞意图可重跑；运行中意图可暂停并恢复，暂停请求使用运行租约及持久化状态，等待 Worker 停止写入后返回。暂停后可向独立 Worker 会话发送人工消息和 @ 引用；普通执行槽占满时仍能处理，并保留请求去重和中断后恢复。隔离数据库、真实 Agent 夹具、竞态检测及浏览器测试覆盖上述流程。计划任务页面与主要日程操作已迁移并通过浏览器、数据库测试。
- 任务分类、备注、置顶和模板管理已接入；模板可保存并应用描述、目标、备注、Worker 数、分类和任务级规则。任务列表支持状态、分类与关键词筛选，置顶排序和分页已通过数据库验证；分类、模板及创建流程已通过浏览器验证。分类与模板按当前产品账号隔离。
- 创建任务可选择最多 8 个同账号来源任务，直接来源的资产、事实、发现和已结束意图以只读方式展示并供 Planner/Worker 使用，不递归继承；来源证据可用于当前目标证明。目标删除、跨账号访问、运行中意图、所选目标范围及来源图写入均有隔离测试。自动编排也能指定来源任务。
- 种子意图可在创建任务时或由自动编排启用：先完成目标拆解，再优先派发种子 Worker；拆解完成状态独立保存，暂停、超时或人工删除任务目标后不会错误地重复初始化。已有工具目录的升级保留用户配置。
- 任务范围支持组织、根域名、子域名、IP、CIDR、备案号和关键词，支持手动与 Agent 登记，显式登记资产时自动添加保守范围；直接来源任务范围只读继承。范围归集、资产列表、未测资产查询及按确认事实估算的覆盖度复用统一资产库，并保留所选目标限制；关闭覆盖度仍可积累范围。隔离数据库、真实 Planner 和浏览器测试覆盖归集、账号及运行租约隔离、目标边界、范围增删和组织名称。关键词按 ARTEX 原版仅保存，不参与当前覆盖匹配。
- 待领取、运行中和已暂停意图支持保留式或彻底删除，必须填写原因；运行中的 Worker 停止后才清理，并通过持久命令处理进程中断。彻底删除仅移除独占后代，保留共享和跨任务引用、平台资产与已有风险，并汇总已删除执行记录的 Token；有运行中后代或活跃复测时拒绝彻底删除。规划者收到删除原因，页面显示等待与冲突状态。真实 Worker/Planner、隔离数据库和浏览器测试覆盖删除、恢复、共享证据和权限；原版删除结果的详细计数展示仍未对齐。
- 任务内 MainAgent 支持分段会话、历史和独立上下文；任务暂停或结束时仍可后台对话，普通消息不会启动任务，新增目标或意图后通过持久化事件唤醒任务。对话使用独立租约，可停止单次回复，页面复用 ARTEX 的执行轨迹和审批组件，支持当前任务附件与按分段隔离的旁路提问。隔离数据库、真实 Agent 及模型夹具、竞态检测和浏览器覆盖目标与账号限制、过期租约、重复请求、断开请求、停止、附件、资产查询登记、审批与分段隔离。任务详情和执行视图的其余布局仍未完整对齐。
- Planner、Worker 和 MainAgent 可调用任务范围内的 `list_assets`，自动编排等对话 Agent 可查询当前账号可访问的资产；两者复用原版 DSL 解析器并查询统一资产库，支持按 ID、域名、组织、状态码、技术及端口等条件查询。任务数据仍受账号、运行租约及所选目标限制；独立对话受会话租约和账号限制。真实 Planner、ChatAgent 与工具目录测试覆盖多组织、扫描端口、已删除目标、范围外 ID、跨目标观察及授权开关。扫描端口仍使用平台现有的 IP 资产身份，而不是虚构新的端口资产 ID。
- 任务情报已接入运行设置开关、独立记录、事实附带情报、服务认证信息归集、去重、分类、状态处理和来源任务只读查看。新情报主记录的内容与证据使用现有 AI 密钥加密；Agent 执行轨迹和模型会话仍可能包含原始工具输入，不应将主记录加密视为所有副本都已加密。数据库、真实 Worker 和浏览器测试覆盖开关、去重、来源、账号、目标与租约边界。
- 默认凭据整理 Agent 已接入独立模型和提示词设置、规则优先解析、单次模型整理、原文校验、持久租约、关闭取消和手动重试；整理结果加密保存，原始情报及人工状态保留。启用凭据流量关联后，仅在当前任务已录制流量中同时匹配主机和凭据，不发起登录或其他网络请求；匹配片段加密保存，原始流量删除后仍可查看片段。数据库测试覆盖多进程争抢、失效租约、关闭与恢复、开关变更中的旧结果拒绝、错误重试、继承、历史结果、用量归属和归档屏障，浏览器测试覆盖开关和结果展示。 源码新增空闲预检查：所有账号均未启用时跳过队列恢复查询，启用后下次轮询继续处理；该预检查已部署至本机，不能视为数据库进程段错误的根因修复。
- HTTP 流量录制已接入任务及独立对话运行，按账号与任务或会话隔离，并继续使用系统设置的上游代理；任务页与对话页支持按主机、方法、状态码、正文、路径、响应大小筛选，支持排序、分页、请求响应详情和大正文分段读取，任务触发的 Agent 流量归入来源任务。漏洞支持人工关联、编辑、排序、解除关联及独立证据快照，也支持 MainAgent 登记漏洞时原子关联和报告 Agent 补绑；版本冲突、租约和账号/目标边界已通过隔离数据库及真实 Agent 夹具验证。录制开关对新启动的 Agent 运行生效；原版录制器对 SSE 和至少 5 MiB 的流式请求或响应不保存该流量，当前仍保留此限制。原始录制及证据快照可能含明文请求头、凭据和正文，并非全部加密。
- 全局流量列表已在代码中汇总当前账号的任务与独立对话记录，提供主机数量、名称搜索、来源名称、筛选、排序、分页和各来源详情；数据库、竞态及浏览器测试覆盖账号隔离、目标或会话删除、权限变更和跨存储分页。此项已部署至本机；全局流量删除和存储回收仍待迁移。
