# 网络空间搜索

本模块提供 FOFA 凭据配置、显式分页查询及选中结果同步。生产请求固定访问 `https://fofa.info`，凭据由后端加密保存；普通查询不返回 API Key，不自动重试计费查询。

查询结果由服务端保存为一小时有效的账号专属快照。同步只接受快照 ID、行号和目标组织/目标，资产内容从快照读取。每条结果在独立事务中复用 Catalog 目标创建/组织绑定、原资产应用接口和统一资产登记；失败回滚该行，重复同步使用同一账本结果。

自动模式根据结果主机的可注册根域名创建或复用目标，并将目标关联到所选组织；子域名、站点和端口仍按原主机登记。根域名按公共后缀规则提取，不依赖 FOFA 提供的 domain 字段。IP 结果按地址创建或复用目标；IPv6 literal 受原 Target/HostPort 边界限制，只写统一资产库并返回说明。指定已有目标时必须通过原资产范围校验。FOFA 报告的 IP 关联不伪装为已验证 DNS 记录或漏洞。

参考协议：[FOFA 官方 API](https://fofa.info/api)、[官方 Python SDK](https://fofapro.github.io/fofa-py/_modules/fofa/client.html)。仅请求基础字段，账户权限和查询额度由 FOFA 返回结果决定。
