# 信息收集报告布局参考

实际中英文报告由 `scripts/recon_report.py` 从统一模型生成，此文件作为布局说明，不由脚本进行字符串替换。

报告顺序：

1. 规范化目标、run、执行状态、模式、生成时间和资产计数。
2. 各阶段 success / partial / failed / skipped 状态及原因。
3. HTTP、Web 选取、端口后端和云桶预算的实际覆盖范围。
4. 按真实 IP/协议/端口列出的服务与原始证据路径。
5. AXFR 逐 NS 结果、敏感路径、匿名接口、云桶和前端候选；区分观察与结论。
6. 组织/ASN 待核对线索。
7. manifest、commands、JSON 和 raw 证据索引。

未执行、失败、超时或受限的检查应直接说明，不用“未发现漏洞”填充。正文可限制预览数量，完整机器数据应保留，选取预算写入 coverage。
