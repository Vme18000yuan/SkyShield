- 新增 SkyShield 本地与 Docker 部署统一的版本检查及管理员确认安装流程，替换本产品对上游 LunaFox 更新配置的依赖。
- 更新进程独立运行在宿主机，通过私有 Unix socket 与 Server 通信，保留升级阶段和结果，支持 systemd 管理。

- 新增固定源码提交与镜像摘要的稳定发布渠道及生成工具。

首次接入需要在维护时间更新部署脚本和服务一次，之后可通过“关于天穹”检查及安装后续版本。自动安装要求官方 Git 克隆目录；旧版部署和 ZIP 部署请参考 docs/16-系统更新.md。

本次完成静态检查和 linux/amd64 镜像构建，没有在当前运行环境执行完整升级、断线恢复或数据库恢复测试。应用停止后出现故障会进入需要恢复状态，不自动回退数据库。
