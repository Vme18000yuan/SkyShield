# v0.0.1-alpha.229

## English

### Fixed

- Fixed dropdown menus, popovers, tooltips, and select popups opening at the corner of the viewport instead of next to their trigger when the operating system asks for reduced motion.

### Development update

- Asset monitoring now retains GeoIP city metadata, supports zoomable city labels, and returns the latest 50 discoveries.
- This update adds migration 000077. Take a database backup before the manual upgrade; follow the [deployment guide](../docs/public-deployment.md). Local development uses `./local.sh start` after active scans finish.

Full Changelog: https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.228...v0.0.1-alpha.229

## 简体中文

### 修复

- 修复在系统开启“减少动态效果”时，下拉菜单、气泡、提示和下拉框弹层出现在视口角落而不是触发按钮旁的问题。

### 开发版本更新

- 监控大屏保留城市定位信息，支持地图缩放与城市名称，并展示最近 50 条资产。
- 本次新增迁移 000077。手动升级前请备份数据库，并遵循[部署指南](../docs/public-deployment.zh-CN.md)；本地开发环境在扫描结束后执行 `./local.sh start`。

完整变更记录：https://github.com/yyhuni/lunafox/compare/v0.0.1-alpha.228...v0.0.1-alpha.229
